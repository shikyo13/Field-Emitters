# Field Emitters 1.0.1

- Fixed zero FE cost disabling connected forcefields. Setting the server cost to zero now allows free operation; unlinked emitters remain idle.
- Fixed large energy buffers overflowing the network total and shutting down otherwise powered fields.

The release is being prepared. Only the NeoForge 1.21.1 build has been validated so far; other loader/version files must pass their own validation before release.
