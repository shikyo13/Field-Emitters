# Publishing records

Files used for the CurseForge and Modrinth listings and the GitHub release.

| File | Purpose |
| --- | --- |
| `description.md` | Project description for CurseForge. |
| `description-modrinth.md` | Project description for Modrinth. |
| `release-notes-<version>.md` | Changelog text for the GitHub release and both platforms. |
| `external-links.json` | Issue tracker, source, wiki, Discord and support links entered on each platform. |
| `gallery.json` | Gallery images, captions and upload results. |
| `curseforge-icon.png`, `modrinth-icon.webp` | Project icons. |
| `release-<version>.json` | Uploaded file names, hashes, platform IDs and download URLs. |

Screenshots are unedited captures from the release build at the game's native resolution.
