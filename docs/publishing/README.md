# Publishing records

Files used for the CurseForge and Modrinth listings, the GitHub release and the showcase video.

| File | Purpose |
| --- | --- |
| `description.md` | Project description for CurseForge. |
| `description-modrinth.md` | Project description for Modrinth, with the showcase embed after the introduction. |
| `release-notes-<version>.md` | Changelog text for the GitHub release and both platforms. |
| `external-links.json` | Issue tracker, source, wiki, Discord and support links entered on each platform. |
| `gallery.json` | Gallery images, presentation images and the video, with captions, hashes and upload results. |
| `gallery/` | The unedited in-game captures at their native resolution. |
| `curseforge-icon.png`, `modrinth-icon.webp` | Project icons exported from the showcase icon composition. |
| `field-emitters-logo-master.png`, `logo-manifest.json` | The 2048-square icon master and the export record. |
| `youtube-upload.md` | The published showcase video, thumbnail, title, description and embed placement. |
| `release-<version>.json` | Uploaded file names, hashes, platform IDs and download URLs. |

Screenshots are unedited captures from the release build at the game's native resolution. The presentation images and the video come from [the media folder](../media/README.md) and its [editable source](../../tools/showcase/README.md).
