# Rails and bridges

Field Rails mount against blocks and project toward an opposing rail. The default maximum distance is 20 blocks. Adjacent rails share settings and energy.

## Make a bridge

1. Mount rails against solid blocks on opposite sides of the gap, facing each other.
2. Add matching pairs beside them to make the bridge wider.
3. Connect an energy source to any rail.
4. Open a rail's controls, go to **Connections**, and click **Bridge mode**.

Bridge mode makes the field horizontal and sets the blocking rules to support everyone, including the owner. Entities can pass upward through it. It replaces the existing blocking filters and direction overrides, and turns damage off.

Wait for the field to form before stepping onto it. The bridge disappears when it loses power. Changing Blocking afterward can let players fall through; for example, enabling **Skip owner** lets the owner pass through their own bridge.

## Make a wall

Use **Field shape** in Connections to choose a vertical orientation, then set Blocking for travel through the wall. Changing Field shape changes only the orientation; it does not reset the filters.

Rails facing each other from a floor and ceiling form a vertical field. For a doorway, place one row on the floor and a matching row on the lintel. The available field shapes depend on how the rails are placed.

## Connected rails

Connected rails use one set of network settings. One energy input and one redstone control input can run the group. For sensor output, connect your circuit to the rail at the **Redstone output at** coordinates, using the **Output side** selected in Sensor.

Rails connect to rails. Field Emitter posts connect to other posts.
