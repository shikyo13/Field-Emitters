# Forge and Fabric port validation — 1.0.1

All four ports built and ran in isolated development profiles. User CurseForge saves and installed profiles were not modified.

Each loader/version directory records real crafting-menu transactions, connected-field manager and all five editor tabs, blocking/automation/rail verification, native loader energy simulation or transaction rollback, zero-cost and three-billion-FE regression cases, final remote color edits, survival rail harvesting and native connected impact screenshots. Post middle-section harvesting also returned one emitter on each port; the first harness assertion counted the same inventory slots twice and was corrected. Forge rail pickup initially missed items falling through the mined fixture floor; a shorter mining interval confirmed one normal drop. Neither was a mod defect.

Dedicated servers reached Done and saved on shutdown. Fabric client networking was separated from common initialization after dedicated startup exposed an accidental LocalPlayer class reference. Forge 1.21.1 needed pack metadata for resources to load. Minecraft 1.20.1 advancement item predicates were converted to arrays. Fresh demo levers now use the actual west input face.

Crafting used actual ingredient consumption, including stained glass. Energy verification calls the native public Forge FE capability or Fabric transactional storage; Fabric rollback leaves energy unchanged. Configs were restored after regression tests. A small 320-by-240 logical GUI was exercised with actual scaled mouse clicks on Fabric 1.20.1. Gameplay verification covers post and rail barriers, directions, ownership, sensors, terrain, stacked strips and floor fields. Final remote editor tests reached server block-entity data after the client-only networking correction.

Limits: dedicated startup is not a two-client multiplayer session; no large-network performance benchmark was performed. Native port impact images are runtime evidence. The polished baseline animation video and GIF are in ../../media/impact-captures/.
